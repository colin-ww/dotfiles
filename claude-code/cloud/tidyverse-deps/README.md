# tidyverse dependency map

`tidyverse-deps.yml` is generated by `gen-tidyverse-deps.R`; don't edit it by hand.

```sh
# from the repo root, with tidyverse installed
Rscript claude-code/cloud/tidyverse-deps/gen-tidyverse-deps.R
```

Counts are from the *installed* versions (see `meta:`), so re-run after a tidyverse update.
"dep" = Depends + Imports + LinkingTo (what `install.packages()` pulls in); base and
recommended R packages are excluded. Every list has a `# n = <count>` comment.

| key | what |
|---|---|
| `core` | attached by `library(tidyverse)` (9) |
| `non_core_members` | installed on purpose (tidyverse's Imports) but not attached (21) |
| `all_deps` | everything `install.packages("tidyverse")` ends up with (99) |
| `transitive_only` | `all_deps` minus the members: only there as someone's dependency |
| `core_graph` | who directly depends on whom, core only |
| `member_graph` | same across core + non-core members |
| `packages.<pkg>` | per member: `direct`, `recursive`, and `beyond_dplyr` (recursive deps that dplyr and its deps don't already bring in) |
